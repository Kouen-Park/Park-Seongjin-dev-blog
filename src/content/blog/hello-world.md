첫 글입니다.

개발하면서 배운 것, 삽질한 것, 만든 것을 하나씩 기록해보려고 이 블로그를 만들었습니다.

개발하다 보면 분명 며칠 전에 해결했던 문제인데 다시 검색하고 있는 경우가 많습니다. 에러 하나를 해결하려고 공식 문서를 읽고, Stack Overflow를 뒤지고, GitHub Issues를 탐험하다가 겨우 해결해놓고도 며칠 뒤에는

> "이거 어떻게 해결했었지?"

하고 있는 저를 발견합니다.

그래서 이제는 미래의 저에게 조금이라도 친절해지기로 했습니다.

결과만 적어두기보다는 어떤 문제를 만났고, 무엇을 시도했고, 어디서 삽질했고, 결국 어떻게 해결했는지까지 기록해보려고 합니다.

## 왜 블로그인가

### 기록

개발하면서 만난 문제와 해결 과정을 남겨두면 다음에 같은 문제를 만났을 때 훨씬 빠르게 해결할 수 있습니다.

적어도 같은 에러를 두 시간 동안 두 번 해결하는 일은 줄어들겠죠.

가능하면 단순히 정답만 적기보다는,

- 어떤 문제가 있었는지
- 무엇을 시도했는지
- 왜 안 됐는지
- 결국 어떻게 해결했는지

같은 과정까지 함께 남기려고 합니다.

그리고 운이 좋다면 구글에서 에러를 검색하다가 제가 쓴 글을 제가 발견하는 날도 올지 모릅니다.

그 정도면 꽤 성공한 블로그 아닐까요.

### 정리

알고 있다고 생각하는 것과 다른 사람에게 설명할 수 있는 것은 꽤 다릅니다.

머릿속에서는 완벽하게 이해한 것 같은데 막상 글로 설명하려고 하면 갑자기 모든 것이 흐릿해질 때가 있습니다.

그럴 때 보통 둘 중 하나입니다.

정말 어려운 개념이거나,

제가 제대로 이해하지 못했거나.

배운 내용을 글로 정리하면서 애매하게 알고 있던 부분을 발견하고, 다시 찾아보고, 조금 더 제대로 이해해보려고 합니다.

그래서 이곳은 누군가에게 보여주기 위한 공간이기도 하지만, 동시에 제가 공부한 내용을 제대로 이해하기 위한 공간이기도 합니다.

### 포트폴리오

완성된 프로젝트만 보면 그 과정에서 무슨 일이 있었는지는 잘 보이지 않습니다.

처음부터 모든 구조를 완벽하게 설계해서 코드만 작성한 것처럼 보일 수도 있습니다.

물론 현실은 그렇지 않았습니다.

기능 하나를 만들면서 구조를 바꾸기도 하고, 잘못된 선택을 되돌리기도 하고, 한 줄짜리 버그를 찾느라 한참을 보내기도 합니다.

그래서 단순히 "이걸 만들었습니다"에서 끝내지 않고,

왜 이 기술을 선택했는지, 왜 이런 구조로 만들었는지, 어떤 문제가 있었고 어떻게 개선했는지도 함께 기록하려고 합니다.

프로젝트와 함께 제가 어떤 개발자로 성장하고 있는지도 남길 수 있었으면 합니다.

## 무엇을 기록할까

아직 정확하게 정해놓지는 않았지만 주로 이런 내용을 기록할 생각입니다.

- 프로젝트 개발 과정
- 개발하면서 만난 에러와 해결 방법
- 새롭게 배운 기술과 개념
- Git, 배포, 개발 환경에서 겪은 시행착오
- AI 도구를 개발에 활용하면서 배운 것
- 프로젝트 구조나 기술을 선택한 이유
- 직접 만들어본 것들

완벽하게 정리된 튜토리얼보다는 직접 개발하면서 경험한 내용을 중심으로 남기려고 합니다.

잘된 것도 기록하고,

왜 이렇게 했지 싶은 것도 기록할 생각입니다.

어쩌면 후자가 더 많을 수도 있습니다.

## 이 블로그는 어떻게 만들었나

블로그 자체도 작은 개발 프로젝트로 시작했습니다.

Astro를 사용해 만들었고, 글은 Markdown으로 작성합니다. Markdown 파일을 추가하면 Astro가 정적 HTML로 빌드해주는 비교적 단순한 구조입니다.

호스팅은 GitHub Pages를 사용합니다.

현재 배포 과정은 대략 이렇습니다.

```
Markdown 작성 → Git commit → GitHub push → GitHub Actions → Astro build → GitHub Pages 배포
```

새로운 글을 작성할 때는 `src/content/blog/`에 Markdown 파일 하나를 추가하고 커밋하면 끝입니다.

물론 개발에서 "~하면 끝입니다"라는 문장은 높은 확률로 나중에 수정될 가능성이 있습니다.

일단 지금은 그렇습니다.

블로그를 운영하면서 필요한 기능이 생기면 검색, 태그, 디자인 같은 부분도 조금씩 직접 개선해볼 생각입니다.

## 앞으로

처음부터 완벽한 글을 쓰려고 하면 첫 글이 마지막 글이 될 것 같아서 일단 시작했습니다.

짧더라도 꾸준히 기록하면서 프로젝트도, 블로그도, 개발 실력도 같이 발전시켜보려고 합니다.

몇 달, 몇 년 뒤에 다시 이 글을 봤을 때

> "이때는 이런 걸 고민하고 있었구나."

할 수도 있고,

> "대체 왜 이렇게 했지?"

할 수도 있겠죠.

둘 다 나쁘지 않은 기록이라고 생각합니다.

그럼 첫 글은 여기까지.

미래의 제가 이 블로그를 자주 검색하게 되기를 바라며.
