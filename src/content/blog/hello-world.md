첫 글입니다. 개발하면서 배운 것, 삽질한 것, 만든 것을 여기에 기록하려고 합니다.

## 왜 블로그인가

- **기록**: 문제를 어떻게 풀었는지 남겨두면 다음에 같은 벽을 만났을 때 훨씬 빠릅니다.
- **정리**: 남에게 설명할 수 있게 쓰다 보면 내 이해도 선명해집니다.
- **포트폴리오**: 프로젝트를 진행하면서 얻은 결정과 근거가 쌓입니다.

## 이 블로그는 어떻게 만들었나

- **Astro** — 정적 사이트 생성기. 마크다운으로 글을 쓰면 정적 HTML로 빌드됩니다.
- **GitHub Pages** — 무료 호스팅. `main` 브랜치에 글을 push하면 GitHub Actions가 자동으로 빌드·배포합니다.

새 글을 쓰려면 `src/content/blog/` 에 마크다운 파일을 하나 추가하고 커밋하면 끝입니다.

앞으로 잘 부탁합니다.
